# Tiebreaker: The Final Override 🚨

**Only used if teams are tied after Rounds 1 and 2.**

**Time limit: 10 minutes. Fastest correct answer wins outright — no partial
credit, no bonus points, just first past the post.**

## The challenge

The vault's very last security layer needs one more code before it fully
opens. The system spec says:

> "The override code is the count of every whole number between 1 and 9,999
> (inclusive) that contains the digit **7** anywhere in it."

For example, 7, 17, 71, 27, 173, and 7000 would all count. A number like 123
or 4568 would not.

Write code to count them. When you have your number, raise your hand /
shout it out — the first team to submit the **correct** number wins the
tiebreaker outright.

## Rules

- Whole team can work together as usual.
- You must show your code if asked — this keeps things honest and fast to
  verify (a one-liner or a short loop is all you need).
- No calculators-only, no guessing repeatedly — if you submit a wrong
  answer, you can keep working and try again, but the first team to land on
  the *correct* number is the winner, even if another team submitted first
  with a wrong one.
